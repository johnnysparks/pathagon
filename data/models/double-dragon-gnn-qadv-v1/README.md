# Double Dragon · GNN Q/Advantage v1

This is a real Q/Advantage ONNX artifact with the transition-feature input and
action-value output required by the Double Dragon card. Rust owns feature
construction, legal action alignment, Q-seeded PUCT, and the WASM binding.

The artifact is browser-playable, but its strength status is provisional. The
source research ladder found that this family had unstable paired strength, so
the card does not claim a win probability or a cleared strength promotion.
