# Local learning tournaments

The intended near-term workflow is local and reproducible: clone the repo on
another Mac, install the pinned toolchains, generate Rust archives, merge them,
and warm-start or retrain the GNN from the resulting schema-v2 JSONL.

## First setup on a new Mac

```bash
git clone git@github.com:johnnysparks/pathagon.git
cd pathagon
rustup toolchain install 1.98.0
cargo test --manifest-path engine-rs/Cargo.toml --all-targets --release
python3 -m venv .venv-pathagon-gnn
. .venv-pathagon-gnn/bin/activate
python -m pip install -r learning/gnn/requirements.txt
```

Node dependencies remain available for the browser and TypeScript parity
tests with `npm ci`.

## Generate and submit a local batch

The Rust binary is the high-throughput path. It is currently a 7×7, 14-piece
engine, with deterministic seeds and color-balanced games:

```bash
./scripts/run-rust-archive.sh macbook-lunatic-001 1000 20260824 lunatic
```

That writes a replay archive to `training/gnn/league/` and a compact indexed
corpus to `training/rust-v1/`. Commit and push those files from the generating
machine; another machine can merge them without hand-editing JSON:

```bash
python scripts/merge-replay-archives.py \
  --size 7 --reserve 14 \
  --output training/gnn/rust-7x7-combined.jsonl \
  training/gnn/league/rust-lunatic-7x7.jsonl \
  training/gnn/league/macbook-lunatic-001.jsonl
```

The merger accepts both JSONL replay files and the `games` array inside league
archives, deduplicating exact records and rejecting mixed board configurations
when `--size` and `--reserve` are supplied.

## Warm-start or retrain

Rust records contain actions and outcomes, so they can directly seed a
supervised replay warm-start:

```bash
python -m learning.gnn.train warmstart \
  --data training/gnn/rust-7x7-combined.jsonl \
  --size 7 --reserve 14 --steps 2000 \
  --out training/gnn/pathagon-rust-7x7-warmstart.pt
```

Then continue with GNN self-play, using the resulting checkpoint as
`--resume`. The archive format is intentionally independent of the runner:
the same Rust binary can later run inside a cloud job, and the resulting JSONL
can be merged into the same local training set.

## Current Rust arena

`training/gnn/league/rust-lunatic-7x7.jsonl` contains 100 local Pathfinder vs
Lunatic games, with 96 Pathfinder wins, 4 Lunatic wins, no draws, 2,724 plies,
and 2,464 indexed positions. It was generated by the release Rust binary at
0.516 games/second on the current machine.
