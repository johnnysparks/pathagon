# Documentation

This directory is the project index, not an archive. Documentation tied to one
app, engine, dataset, or research path lives beside that code or data.

For opponent learning, begin with [`RESEARCH.md`](RESEARCH.md). The project is
building learned intuition as a calibrated advisory layer inside the native
Rust search, with separate action and value evaluation and explicit strength
and cost gates. The dated research archive preserves failures as evidence; it
is not a list of defaults to retry.

- [`GAME.md`](GAME.md) — game rules and terminology.
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — monorepo ownership and promotion flow.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to change supported code and data.
- [`DATA.md`](DATA.md) — durable data and artifact policy.
- [`RESEARCH.md`](RESEARCH.md) — current research direction and open questions.
- [`../research/`](../research/) — historical experiment narratives and local work.
- [`../apps/web/README.md`](../apps/web/README.md) — browser app and deployment status.
- [`../pathagon/engine-rs/README.md`](../pathagon/engine-rs/README.md) — supported engine.
