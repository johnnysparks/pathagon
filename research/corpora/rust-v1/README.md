# Rust self-play corpus v1

Canonical seed batch generated by the native engine in GitHub Actions from seed `20260823`.

- 64 deterministic paired-color games
- Pathfinder: 34 wins
- Surveyor: 27 wins
- Draws: 3
- 2,332 total plies
- 2,076 unique searched position/action entries
- 908,563 search nodes
- Search configuration: depth 2, 12,000-node ceiling, 49-move beam, four random opening plies, 120-ply game ceiling

This is a plumbing and reproducibility baseline, not an Elo result. The four random opening plies deliberately create different branches; the tracked position book allows later runs to reuse exact, sufficiently deep answers.

`games.tsv` is the permanent evidence. `positions.tsv` is the reusable strategy cache. Both are deterministic and sorted so meaningful strategy changes remain visible in Git diffs.
