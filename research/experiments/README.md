# Experiment records

Each serious agent-search, training, or evaluation attempt gets a dated
directory here, including failed and inconclusive attempts. Follow
[`docs/EXPERIMENTS.md`](../../docs/EXPERIMENTS.md) and start from
[`TEMPLATE.md`](TEMPLATE.md).

Store the experiment narrative, machine-readable manifest, canonical game-key
references, decisions, and external artifact hashes here. Do not copy replay
payloads, checkpoints, optimizer state, or model-specific tensors into an
experiment directory by default.
